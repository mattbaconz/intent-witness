# Research Snapshot — 2026-08-14

## Category state

The “make AI-generated frontends less generic” category is already crowded and validated.

Observed public projects include:

- Hallmark — direct anti-AI-slop design skill for Claude Code, Cursor, Codex.
- Impeccable — design guidance/refinement ecosystem with browser iteration and deterministic audit/detection work.
- Anthropic frontend-design — official intentional/distinctive frontend generation guidance.
- UI/UX Pro Max — broad design intelligence across styles, palettes, typography, UX guidance, product types, and many platforms.
- Superdesign — IDE-native design agent/skill with references, codebase context, branchable drafts, continuity.
- Microsoft frontend design review skill — explicit design-review skill category signal.

**Strategic conclusion:** A generic SKILL.md that says “avoid AI slop” is not enough.

## Performative UI signal

Performative UI packages recognizable AI/startup design tropes as satire. Its existence and public attention are evidence that interface convergence is culturally recognizable.

**Strategic conclusion:** pattern recognition is useful research material, but banning those patterns would be simplistic.

## ADE capability state

### Cursor
Public docs describe Agent Skills, subagents, hooks, browser tooling, and tool extensibility. Strongest V0 host.

### Codex
Official OpenAI docs describe Agent Skills, customization, subagents, and MCP-related workflows. Good portable target.

### Kiro
Official docs describe portable Agent Skills, custom agents/subagents in isolated context, hooks, and MCP/steering ecosystem.

### OpenCode
Official docs describe SKILL.md skills, specialized agents with custom prompts/models/tools, and MCP servers.

### Windsurf / Devin Local
Official docs describe skills, hooks, MCP servers, plugins/customizations in the local agent environment.

### Google Antigravity
Official docs describe Agent Skills, MCP, agent tools including browser control, and plugin/customization mechanisms.

**Strategic conclusion:** Deliberate can plausibly be a portable protocol with thin adapters, rather than a Cursor-only plugin.

## Skill commoditization

The 2026 GitSkills research reports a very large population of SKILL.md files across public GitHub repositories. Regardless of exact future counts, this reinforces a central strategic point:

> **The markdown skill itself is packaging, not moat.**

## Key research uncertainties

- Whether independent review materially beats strong generation skills in practice.
- Whether fresh-context subagents outperform self-review enough to justify complexity.
- Whether browser screenshot review reliably catches IA/interaction issues.
- Whether users tolerate additional review latency.
- Whether Deliberate can avoid creating its own style convergence.

These uncertainties are resolved by [[EVAL-STRATEGY]], not more brainstorming.
