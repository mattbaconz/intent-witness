# Brand and Naming

## Working name

**Deliberate**

The name encodes the product thesis:

> The problem is not a specific visual trope; the problem is design decisions made on autopilot rather than deliberately.

## Why the name works

- broad enough to survive anti-slop trend cycles;
- can describe a skill, CLI, OSS project, or future company;
- naturally supports product language: “Deliberate review,” “use Deliberate,” “make this deliberate”;
- does not imply objective beauty scoring;
- positions around judgment/intent rather than cosmetics.

## Possible public descriptor

**Deliberate — design judgment for coding agents.**

Alternative:

**Deliberate — the independent design reviewer for AI-written interfaces.**

## Brand personality

- rigorous, not pretentious;
- opinionated about process, not one aesthetic;
- direct and developer-native;
- willing to say “this is uncertain”;
- slightly irreverent in marketing, precise in technical docs.

## Visual brand guidance

Do not accidentally make the Deliberate website the stereotype it criticizes.

Avoid a forced “anti-slop aesthetic” of black/white/mono/square purely to signal taste. The site should demonstrate product-specificity by making **review evidence and before/after reasoning** the visual center.

## Naming risk

No trademark, company-name, domain, npm, GitHub organization, or package clearance has been completed in this vault. This is mandatory before public launch.

Potential package fallbacks if exact package is unavailable:

- `deliberate-ui`
- `deliberate-review`
- scoped package such as `@deliberate/cli`

Do not choose package names without checking current registries.
