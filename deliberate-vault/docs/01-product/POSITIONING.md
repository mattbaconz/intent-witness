# Positioning

## Category

**Design judgment for coding agents** / **automated product-design review for AI-written interfaces**.

Avoid positioning Deliberate as merely:

- “anti-AI-slop skill”;
- “UI linter”;
- “design system generator”;
- “another frontend prompt.”

Those phrases can be acquisition hooks, but they undersell the intended system.

## Primary tagline candidates

Canonical internal recommendation:

> **Stop letting coding agents design on autopilot.**

Other useful lines:

- **Give coding agents design judgment.**
- **Your UI compiled. That doesn’t mean it was designed.**
- **The independent design reviewer for coding agents.**
- **Build → render → review → revise.**

## Core positioning statement

For developers using AI coding agents who are frustrated by polished-but-generic frontend output, Deliberate is an open-source design review layer that independently inspects the rendered product, challenges unjustified design decisions, and forces deeper revisions when needed. Unlike design prompt packs or style libraries, Deliberate does not impose a house aesthetic; it evaluates whether the interface follows from the product’s intent and design language.

## Competitive separation

### Versus generation skills
“Use them. Deliberate reviews what they produce.”

### Versus component libraries
“Use any component system. Deliberate reviews whether the composition and interaction make sense.”

### Versus design systems
“Design systems enforce consistency. Deliberate asks whether the chosen structure is the right one.”

### Versus visual regression tools
“Visual regression tells you what changed. Deliberate asks whether the change is a good product decision.”

### Versus human designers
“Deliberate does not replace human product/design judgment. It catches obvious agent-default decisions earlier and makes AI-generated work easier to review.”

## Claims to avoid

Do not claim:

- “objectively measures good design”;
- “eliminates AI slop”;
- “replaces designers”;
- “guarantees beautiful UI”;
- “detects AI-generated UI with forensic certainty.”

Preferred language:

- “flags likely model-default decisions”;
- “identifies design risks”;
- “checks product-specificity and hierarchy”;
- “forces independent review”;
- “reduces generic convergence.”
