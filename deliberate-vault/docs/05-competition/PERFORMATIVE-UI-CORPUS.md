# Performative UI as Research Corpus

## Context

Performative UI is a satirical component library that intentionally packages recognizable contemporary AI/startup interface tropes. It is useful to Deliberate because it makes cultural convergence explicit.

## What to learn from it

Potential performative pattern families:

- glowing/animated CTA emphasis;
- gradient headline emphasis;
- AI prompt-box hero;
- token/live-generation theater;
- aurora/glow backgrounds;
- logo/social-proof marquees;
- decorative graphs/nodes;
- excessive status chips/pills;
- “frontier AI” visual signaling detached from actual workflow.

## What not to do

Do not copy a list of Performative UI components into a global “forbidden” ruleset.

Why:

- many individual patterns can be excellent in context;
- the satire is deliberately exaggerated;
- today's trope becomes tomorrow's neutral convention;
- banning a style creates a new anti-slop style.

## Deliberate interpretation

Use “performative load” as a reasoning prompt:

> Are the most visually salient elements communicating product capability/state/action, or mostly communicating category/brand theater?

This is especially relevant on AI marketing pages where models are likely to reproduce learned category signals.

## Synthetic fixtures

Create deliberate synthetic examples rather than copying library assets:

1. **High performative / low function:** giant gradient AI headline, prompt box, glow orb, generic logos; product capability unclear.
2. **High performative / justified:** art/creative AI product where generative motion is the core capability and the hero directly demonstrates it.
3. **Low performative / bad:** boring but structurally confusing enterprise dashboard.
4. **Low performative / good:** restrained utility UI with clear workflow.

This tests that Deliberate is not merely an aesthetic anti-trope filter.

## Research questions

- Can reviewers distinguish “decorative but justified” from “decorative default”?
- Does category context bias the reviewer into anti-AI minimalism?
- Are high-salience elements tied to primary user outcomes?
- Does removing performative decoration actually improve the product, or merely flatten the brand?
