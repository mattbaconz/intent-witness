# Product Intent — Intent Witness

## Product

**Name:** Intent Witness<br>
**Domain:** Design-judgment tooling for coding agents  
**Target users:** engineers using Cursor (V0) who want product-specific UI instead of model-default layouts

## Primary job

Run an independent review of a rendered interface against this product’s intent, then force depth-aware revision before the builder declares the UI done.

## Primary objects

- product intent
- review finding
- problem depth
- revision constraint
- comparison

## Critical states

- REVISE with evidence
- PASS / PASS_WITH_NOTES
- INSUFFICIENT_EVIDENCE
- comparison after revision

## Desired product traits

- specific
- evidence-based
- host-portable by protocol
- no house aesthetic

## Explicit avoid

- universal bans on cards, gradients, fonts, or dark mode
- numeric slop/beauty scores
- blocking hooks in V0
