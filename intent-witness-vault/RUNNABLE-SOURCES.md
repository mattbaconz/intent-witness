# Runnable Sources

The vault is specification and research material, not an executable distribution.

The only runnable Intent Witness sources are the repository-root `skill/`, `adapters/`, `schema/`, and `templates/` directories. Use `scripts/install-cursor.mjs` to create installed Cursor copies. Do not recreate skill or adapter trees in this vault.
